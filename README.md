# Nabolagshelse app

**Nabolagshelse** is an analysis platform for geographic data on health, quality of life and local communities for the entire country.

## 🛠 Development

### 🔧 Clone and Set Up the Nabolagshelse Repository

To get started, clone the Nabolagshelse repository and install the necessary dependencies:

```bash
git clone https://github.com/nabolagshelse/nabolagshelse-app.git
cd nabolagshelse-app
npm install
```

### 🌐 Development Server

Start the development server at [http://localhost:3000](http://localhost:3000):

```bash
npm run dev
```
