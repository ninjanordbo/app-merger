Nabolagshelse 
Folkehelsedata og levekårsanalyse for kommunal planlegging

Nabolagshelse er en dataplattform som gir kommuner kvalitetssikrede folkehelsedata og levekårsindikatorer på sonenivå. Plattformen er utviklet for å støtte kommunal planlegging, folkehelsearbeid og målrettede tiltak i lokalsamfunn.

Plattformen er for:

Kommunale planavdelinger
Enheter for folkehelse og levekår
Kommuneoverleger og folkehelsekoordinatorer
Analytikere som jobber med levekår, helseulikhet og tjenestetilbud

Problemer som Nabolagshelse løser:
Fragmenterte og vanskelig tilgjengelige folkehelsedata fra flere kilder
Manglende oversikt over levekår og helseulikhet på sonenivå
Tidkrevende prosesser for å hente ut, vaske og analysere data
Utfordringer med å bruke data aktivt i kommunal planlegging og politikkutforming

Nøkkelfunksjoner

Folkehelsedata på sonenivå
Aggregert statistikk for helse, levekår og demografi på geografiske soner i kommunen
Støtte for å sammenligne soner internt i kommunen og med nasjonale referanser
Levekårs- og helseindikatorer
Indikatorer basert på blant annet SSB-data, helseregistre og kommunale data
Mulighet til å se utvikling over tid og identifisere trender
Kommunal helse- og levekårsanalyse
Visualiseringer som gjør det enklere å oppdage områder med særskilte utfordringer
Verktøy som støtter prioritering av tiltak og ressursbruk basert på dataanalyse
Støtte til kommunal planlegging
Underlag til folkehelselovens krav om oversiktsarbeid
Relevante data til kommuneplan, temaplaner og politiske saker
Eksporterbare figurer og tabeller til folkehelserapporter og saksframlegg

Typiske bruksområder

Forberede folkehelseoversikter og levekårskartlegginger
Dokumentere helseulikhet og sosiale forskjeller mellom soner
Underbygge behov for helsetiltak i lokalsamfunn
Gi politikere og ledelse et bedre beslutningsgrunnlag basert på analyse
Evaluere effekter av tidligere tiltak over tid

Data- og indikatorgrunnlag

Nabolagshelse bruker og kombinerer data fra blant annet:
Offentlige statistikkilder (for eksempel SSB)
Kommunale fagsystemer og registre der det er aktuelt
Store surveyundersøkelser
Demografiske data, levekårsindikatorer og helseindikatorer

Alle data behandles i tråd med gjeldende regelverk for personvern og anonymisering på aggregert nivå.
